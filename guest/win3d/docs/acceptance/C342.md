# C342. D3D9 dynamic buffer locks

Wine's `d3d9_visual` exercises NOOVERWRITE with and without DISCARD
at `visual.c:25148` and draws from a buffer that is still locked
with DISCARD at `visual.c:26917`.

The D3D9 runtime can leave WriteOnly unset on these locks. Passing the
resulting read flag to Gallium disabled the threaded context's storage
replacement on DISCARD. A staged write also left draws issued before
Unlock reading the old data.

DISCARD and NOOVERWRITE buffer locks now use write maps. Dynamic vertex
and index buffers use directly mappable, coherent storage. A whole-buffer
DISCARD can replace busy storage while prior draws retain their
allocation. NOOVERWRITE, including a lock with both flags, maps the
current allocation. [Mesa patch](../../patches/mesa/d3d9-map-dynamic-buffers-directly.patch)

The signed package from `bdd70b48` ran on helios with the Windows 11
`26100.1742.11#win3d` template. Wine 11.0's `d3d9_visual` completed
206,068 checks with 31 skips on each GPU.
