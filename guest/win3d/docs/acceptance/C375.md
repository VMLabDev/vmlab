# C375. Direct3D 11 high resource count

Wine's `test_high_resource_count` uses 100 shader resources and two sampler
states in one pixel shader. It samples each of 50 textures with both samplers
and loads 50 typed buffers. The two checks read the same render target before
and after a buffer write with `D3D11_MAP_WRITE_DISCARD`.

## Trace

Both [C328](C328.md) runs, on AMD1 and Nvidia2, logged this sequence for
`d3d11_d3d11.exe` (timestamps and shader addresses omitted):

```text
shader TGSI translation failed owner=d3d10umd-shader component=sampler-binding-map reason=combined-slot-limit resource=32 sampler=0 target=2 slots=32 action=abort-translation
ERROR pixel shader needs more than 32 combined texture slots owner=d3d10umd shader=… action=draw-zero
```

| Wine check | Expected RGBA | Read back on both GPUs |
| --- | --- | --- |
| `d3d11.c:36343`, first draw | (1274, 637, 1225, 0) | (0, 0, 0, 0) |
| `d3d11.c:36355`, after write discard | (1274, 637, 1325, 0) | (0, 0, 0, 0) |

The source files on helios are
`/home/vmlab/src/stc/card-328-work/runs/final-{AMD1,Nvidia2}/d3d11_d3d11.txt`
and the matching `d3d11_d3d11.errors.log`. Each Wine run reported 476,333
checks, 13 failures and 17 skips. C375 uses those runs and changes only
documentation.

## Why the checks remain open

`declare_compact_sampler_for_resource` in `ShaderTGSI.c` allocates a combined
slot per texture and sampler pair and takes slots from the same map for
typed buffer loads. It rejects the 33rd slot before the shader reaches
Vulkan pipeline creation. The trace therefore identifies the UMD's own
binding limit. `CreatePixelShader` substitutes a zero-output shader, which
accounts for both readbacks.

This shader needs 150 entries in the current representation. Changing
`PIPE_MAX_SAMPLERS` alone would leave the 32-bit masks in
`pipe_shader_sampler_binding_map` and shifts such as `1u << slot` unable to
represent the new entries. The Vulkan path also represents sampled textures
as combined image-sampler descriptors, so a larger map would ask the host
for 100 such descriptors for just two D3D sampler states. A general fix
needs to carry independent texture and sampler indices through translation
and descriptor binding, and handle typed texel buffers at the full resource
count. The archived trace establishes the first failure before any of those
Vulkan descriptor limits are exercised.
