# C374 · Direct3D 11 NV12 textures

The [C328 Wine baseline](C328.md) had 13 Direct3D 11 failures. Eleven came
from `test_nv12`, where every valid even-sized texture returned
`E_OUTOFMEMORY`. Windows advertised NV12 texture creation, but Mesa's
D3D11 frontend had no backing format for the allocation. The test reached
its view, render, and copy checks only after creation worked.

The [Mesa patch](../../patches/mesa/d3d10umd-back-nv12-with-two-texture-planes.patch)
stores luma in a full-size R8 image and interleaved chroma in a half-width,
half-height RG8 image. Typed shader and render-target views select their
plane by format. Initial data, updates, copies and staging maps preserve
the two-plane layout. Copies and updates with odd luma coordinates or
dimensions leave the destination alone.
