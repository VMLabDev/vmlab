# C412. ATI1 texture creation with the runtime's 8-bit pitch

[C376](C376.md) draft A1: `d3d9_visual` and `d3d9_device` ended on an
access violation after ATI1 texture creation returned `E_NOTIMPL`. The
cause is the borrowed-storage change of C343. It takes the row and slice
pitch of a system-memory texture from the runtime, and the runtime does
not describe ATI1 as block storage.
[Fix](../../patches/mesa/d3d9-keep-bc4-layout-for-legacy-ati1-pitch.patch).

## Measured input

A trace build wrote the arguments of every ATI1 call that reaches
`D3D9CopyInitialData` without readback. It is the patch series of this
card plus one `fprintf` in that function. The run used AMD1
(`renderD130`), vmlab-hv, Venus and the Windows 11 `26100.1742.11#win3d`
template. `d3d9_device` made 1,287 such calls and `d3d9_visual` one.
`d3d9ex` made none.

| Texture | `SysMemPitch` | `SysMemSlicePitch` | BC4 row pitch | BC4 slice |
| --- | ---: | ---: | ---: | ---: |
| 1×1, 2×2, 4×4 | 4 | 0 | 8 | 8 |
| 5×5 to 8×8 | 8 | 0 | 16 | 32 |
| 16×16 | 16 | 0 | 32 | 128 |
| 128×128 | 128 | 0 | 256 | 8,192 |
| 257×257 | 260 | 0 | 520 | 33,800 |
| 8×8×8 volume | 8 | 64 | 16 | 32 |

Every call arrived with pool 1 (`D3DDDIPOOL_SYSTEMMEM`), the managed
textures of the Wine tests included. The runtime treats ATI1 as one byte
per pixel: the row pitch is the width rounded up to four, and the slice
pitch is zero for a 2D texture and pitch × height for a volume. In every
call the row pitch was half the BC4 row pitch. `D3D9TextureSubdata`
rejects a row below one block row, so before the fix each of these
creations failed. The Fetch4 call of `visual.c:15637` is the 4×4 row of
the table.

The fix keeps the layout computed from the format when an ATI1 texture
reports a row pitch below the BC4 row pitch. All 1,288 traced calls took
that path. Other borrowed textures still use the runtime's pitches.

## Open

For a 1×1 ATI1 texture the runtime's own layout is four bytes (pitch 4,
one row) and the BC4 upload reads one eight-byte block from that pointer.
The size of the runtime's allocation was not measured. The Wine programs
create 14 such textures and passed.

The Wine JSON summaries, failure logs and the trace files are on helios
under `/home/vmlab/src/stc/card-412-work/amd1-resume` (run 1) and
`/home/vmlab/src/stc/card-412-work/m/ev` (run 2).
