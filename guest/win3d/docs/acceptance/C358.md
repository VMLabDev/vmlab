# C358. D3D9 YUY2 format conversions

Wine 11.0's `d3d9_visual` expects `CheckDeviceFormatConversion` to
return `S_OK` for YUY2 to X8R8G8B8 and YUY2 to R5G6B5
(`visual.c:28024`). Both destinations were already in the ARGB
conversion group. The driver now advertises YUY2 as a source.
[Capability patch](../../patches/mesa/d3d9-report-yuy2-format-conversion.patch)

Wine also uses the query to decide whether to exercise `StretchRect`
and `ColorFill` on YUY2 surfaces. The driver stores packed YUY2 in CPU
memory and converts the requested source rectangle to BGRA. Gallium
scales the converted rectangle and packs it into the destination format.
`ColorFill` writes packed YUY2 pairs into the source surface.
[Surface patch](../../patches/mesa/d3d9-blit-yuy2-surfaces.patch)

The signed package from `fddf3da3` ran on helios using the Windows 11
`26100.1742.11#win3d` template and the vmlab-hv bundle's render server.
The installed x64 driver hash matched the signed package.

| Wine 11.0 `d3d9_visual` | AMD1 (`renderD130`), C342 → C358 | Nvidia2 (`renderD129`), C342 → C358 |
| --- | ---: | ---: |
| YUY2 to X8R8G8B8 query failures | 1 → 0 | 1 → 0 |
| YUY2 to R5G6B5 query failures | 1 → 0 | 1 → 0 |
| Full program assertions executed | 206,068 → 207,441 | 206,068 → 207,441 |
| Full program failures | 2 → 0 | 4 → 2 |
| Skips | 31 → 29 | 31 → 29 |

Both YUY2 skips disappeared on each GPU. Wine ran the YUY2 blit,
readback and color fill assertions with zero failures. Nvidia2's two
remaining failures are the ATI1 fixed-function and `texld` readbacks
at `visual.c:15668` that also failed in C342. The Nvidia2 monitor
observed no Xid events.
