# C359. Nvidia2 ATI1 Fetch4 readback

Card #358 ran only Wine 11.0 `d3d9_visual` on each GPU on helios
with the signed package from `fddf3da3` and the Windows 11
`26100.1742.11#win3d` template. The reports are under
`card-358-work/runs/{amd,nvidia}/evidence`.

| GPU | Executed | Passed | Failed | Skipped |
| --- | ---: | ---: | ---: | ---: |
| AMD1 (Venus on `renderD130`) | 207,441 | 207,441 | 0 | 29 |
| Nvidia2 (Venus on `renderD129`) | 207,441 | 207,439 | 2 | 29 |

Both Nvidia2 failures are at line 15668. The fixed-function and `texld`
rows both read `0x70707070` at (360, 30). The AMD reference is
`0x6d6d6d6d` and the Intel alternative is `0xff6d00ff`. Wine also
accepts the AMD red channel alone on Windows. Both references have red
`0x6d`, so the tolerance of two allows `0x6b` through `0x6f`.
[Wine 11.0 test source](https://github.com/wine-mirror/wine/blob/wine-11.0/dlls/d3d9/tests/visual.c#L15661-L15670).

The D3D9 resource maps ATI1 to `PIPE_FORMAT_RGTC1_UNORM`, which maps to
`VK_FORMAT_BC4_UNORM_BLOCK`. The ATI1 branch in `TEX_if_fetch4`
offsets the coordinates by half a texel, samples with `TEX`, and
replicates the returned red channel. The test writes endpoints 255 and
0 with initial index bits `0xb977`. Both draws select texel (2, 0),
whose index is 5. Reference BC4 decoding gives `3 * 255 / 7`, which
rounds to 109. The published NVIDIA decoder measurements predict
`(65535 - 36 * 4 * 255) / 257` on the same 8-bit scale, which rounds
to 112 and matches the readback. The projected case selects texel
(1, 0), index 6. The model predicts 71 there, within two steps of the
expected 73. That row passed on both GPUs.
[Khronos BC4 decoding](https://registry.khronos.org/DataFormat/specs/1.4/dataformat.1.4.inline.html#rgtc_bc4).
[NVIDIA BC4 decoder measurements](https://fgiesen.wordpress.com/2021/10/04/gpu-bcn-decoding/).

The evidence points to Wine's tolerance for host BC4 decode precision.
The Direct3D 11.3 BC4 error rule allows a term of 3% of the endpoint
span, or 7.65 steps for this block alone. The two Wine assertions
remain outside their narrower tolerance. This card records the
existing runs and changes only acceptance documentation.
[Direct3D 11.3 BCn error tolerance](https://microsoft.github.io/DirectX-Specs/d3d/archive/D3D11_3_FunctionalSpec.htm#BCErrorTolerance).
