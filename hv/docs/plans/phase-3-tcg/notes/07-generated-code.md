# Generated code

## Question
Committed or generated at build time?

## Answer
Committed in its own crate, regenerated by a `just` recipe from the pinned toolchain; CI checks the committed output matches a regeneration.

## Why
Builders need no Sail toolchain; model updates are reviewable diffs. Recommended, accepted.

## Consequences
- Generated crate size and compile time must be measured early (C++ backend emits 591k lines for sail-riscv); split into several crates if compile time hurts.
- Generated files carry their BSD-2 / BSD-3-Clause-Clear notices (HV-D34).
