# WSL2

## Question
How does the viewer run on WSL2?

## Answer
Detect WSLg (/mnt/wslg or a WAYLAND_DISPLAY pointing there) and use the shared-memory frame path with a CPU upload; everything else unchanged.

## Why
dma-buf cannot cross into WSLg.

## Consequences
None.
