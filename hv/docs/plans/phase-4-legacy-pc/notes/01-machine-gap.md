# The i440fx/PIIX machine gap

The remaining work is a pc machine model, legacy storage, floppy DMA, Cirrus graphics and two NIC models. Much of the ISA platform and display delivery can be reused, but register-probe support is insufficient for DOS and Windows drivers. The captured southbridge is a mix of PIIX3 functions and PIIX4 PM, not a complete physical PIIX4. This note compares captured hardware with inspected code, not with a newly booted guest.

## Basis and limits

- F1: The baseline is QEMU 11.1.2, `pc-i440fx-11.1`, SeaBIOS, 256 MiB and one vCPU. It contains both NICs and Cirrus to cover multiple profiles. Its PCI slots are not the exact topology of any one template. /home/wil/dev/vmlab-hypervisor/docs/hwref/pc-seabios-legacy/qemu-version.txt:1; /home/wil/dev/vmlab-hypervisor/docs/hwref/pc-seabios-legacy/guest/dmidecode.txt:20; /home/wil/dev/vmlab-hypervisor/docs/hwref/pc-seabios-legacy/README.md:39.
- F2: The measured boot is Alpine linux-virt 6.12.114 through `-kernel`, not DOS, Windows or TempleOS. It lacks floppy and pcnet drivers. Enumeration proves their advertised resources, not their working data paths. /home/wil/dev/vmlab-hypervisor/docs/hwref/pc-seabios-legacy/README.md:29.
- F3: HV-D23 requires unchanged firmware, HV-D30 requires QEMU-identical hardware unless approved otherwise, and HV-D10 assigns legacy agents COM1. Phase 2 explicitly moves `windows-legacy` to phase 4. /home/wil/dev/vmlab-hypervisor/.scratch/plans/vmlab-hypervisor/MAP.md:45; /home/wil/dev/vmlab-hypervisor/.scratch/plans/vmlab-hypervisor/MAP.md:58; /home/wil/dev/vmlab-hypervisor/.scratch/plans/vmlab-hypervisor/MAP.md:65; /home/wil/dev/vmlab-hypervisor/.scratch/plans/phase-2-modern-vms/MAP.md:28.
