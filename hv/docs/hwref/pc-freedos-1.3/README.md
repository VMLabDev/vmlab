# FreeDOS 1.3

Captured on 2026-10-31 from `x86/freedos-1.3@1.3.0` through `vmlab up dos`,
using QEMU 11.1.2 and KVM. The guest is FreeDOS, not a Linux probe.
`qemu-argv.json` records the running command, and `environment.json`
identifies the executable and template metadata hashes.

## Machine and method

The production `windows-9x` profile supplies pc/i440fx, SeaBIOS, IDE,
Cirrus VGA, PCnet, local-time RTC, and the agent's COM1 UART. COM2 carries
the log. The template supplies one vCPU and 64 MiB. Its metadata does not
pin a CPU model; the captured argv uses `host,vmx=off,svm=off`.

The scratch lab supplies one NIC on an isolated segment and a fixture CD.
The CD contains `HWREF.TXT`, the DOS probe, and a Windows probe used by the
other captures. The image is attached through vmlab's `cdrom` field.
No floppy medium or host device is attached. Only tracing and a second
QMP socket were added to the command generated by vmlab.

The disk is a disposable overlay. Its backing chain and post-stop image
check are recorded beside this file. The VM ran in a user scope capped at
24 GiB with `MemorySwapMax=0`. `cgroup.txt` records the scope.

## Exercised

- E1: Boot reached the DOS agent prompt. `echo capture-ready` returned
  the expected output, and directory commands read the guest's filesystem.
- E2: The DOS probe invoked BIOS VBE mode `0x101`, waited one second,
  and restored text mode 3. The probe does not check the VBE return code;
  it establishes the request and subsequent register traffic, not an
  independent pixel-level validation of that graphics mode.
- E3: The probe wrote, closed, read back, and deleted `C:\HWREF.TMP`.
  Readback was `HWREF DOS DISK CHECK`. It opened `D:\HWREF.TXT` and read
  the expected optical-media text.
- E4: The template's automatic networking did not start PCnet. The existing
  `C:\NET\FDNET\PCNTPK.COM` driver was loaded manually with `INT=0x60`.
  It reported IRQ10 and I/O base `0xc020`. DHCP obtained `10.219.87.2`.
  mTCP refused to ping because its lease check rejected the remaining
  one-hour lease. A separate static configuration using that assigned
  address returned both ping replies with no loss. The failures and
  trailing-whitespace warnings are retained in `exercise.log`.
- E5: Keyboard and pointer events were sent through vmlab, plus HMP
  relative mouse movement. The probe read BIOS keyboard input and the
  CuteMouse INT33 coordinates. The reported keyboard byte was 0; this
  does not independently prove that the typed `a` was consumed correctly.
- E6: The final run ended with QMP `SHUTDOWN`, `guest = true`, and
  `reason = guest-shutdown`.

## Implementer evidence

Device Markdown files list port and MMIO accesses, counts, value sets,
and first-use order. `indexed-registers.json` includes decoded RTC and
device-specific register-event indices. `commands.json` counts ATA/ATAPI
command opcodes. `event-values.json` retains bounded argument samples,
including PCnet initialization and ring-layout events. The final capture
contains 95 PCnet I/O writes, 78 reads, and one PCnet initialization.

Static HMP files record qtree, PCI, memory regions, IRQs, ROMs, and USB.
`acpi/` contains checksummed guest-installed tables read through QMP physical
memory. SMBIOS entry-point and structure binaries are included.
`fwcfg-files.json` inventories the firmware file directory through paused
HMP port accesses with memory-region tracing disabled. Host fw_cfg reads
are excluded from guest-access counts. `cmos-observed.json` contains RTC
register value samples, not a simultaneous full CMOS dump.

## Failed removable-media run

An earlier run read the original CD directory successfully, then lost agent
responsiveness after QMP replaced the CD with an expanded fixture. Its stop
ladder ended in `host-qmp-quit`, not a guest shutdown. The final run attached
the complete fixture before boot. That successful run does not resolve the
live-media failure. The failed run's operations and shutdown events are in
`media-change-failure/`; its raw trace remains untracked in `.scratch/dos-r2`.

## Bounds and untested paths

The final stream contains 3,264,057 events. The raw prefix is capped at
64 MiB, with 2,572,225 later lines omitted. Register and event counts cover
the full stream. Truncated value sets and argument samples are marked.
KVM's in-kernel PIC/PIT paths are not a complete QEMU bus trace.
Physical-memory snapshots can add observer reads to VGA aperture rows;
those aperture counts are not guest-only.
No floppy medium, snapshot, reconnect, suspend, or throughput test ran.
No S1 or S2 implementation changed. These observations do not establish
a vmlab-hv parity pass.
